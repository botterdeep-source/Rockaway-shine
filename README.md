# Rockaway Seasonal Care source

React + TypeScript + Vite website.

## Run locally
- Install Node.js LTS.
- In this folder run `npm install`.
- Run `npm run dev` and open the local URL.
- Run `npm run build` to create the production build in `dist/`.
